# COMP 202 coding

Password-locked notes on core Python ideas (AES-256-GCM, decrypted in the browser). The repo only holds the encrypted `index.html`;
the readable page is built by a script on the owner's computer.

Live: https://ben77g.github.io/comp202-coding/

## Changing the background picture
The background is the picture file in the root of this repo, [`background.jpg`](background.jpg). It shows on the lock screen and behind the page.
To use your own picture: open the [upload page](https://github.com/ben77g/comp202-coding/upload/main), drop your picture in, and commit.
- Easiest: name your file `background.jpg` so it replaces the current one. `background.png`, `background.webp` or `background.jpeg` also work and take priority over the `.jpg`.
- Use a picture about 1920 px wide and under 1 MB; very large photos make the page slow.
- This repo is public, so anything you upload here is public (the notes themselves stay encrypted). The page can take a minute or two to update after you commit.
- To go back to the original hill, delete the file you uploaded (or restore `background.jpg`).
